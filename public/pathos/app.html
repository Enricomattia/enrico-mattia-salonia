Metadata & covers

Nothing here changes your ratings, reviews or dates. Enrichment only adds catalogue information. For books with a StoryGraph ISBN, v0.4 resolves the exact edition first and keeps edition metadata on the reading itself.

Enrich your existing archive

Books use Open Library, with optional Google Books ISBN lookup. ISBN-based StoryGraph entries are treated as exact editions, not merely as works. A cover is now saved only when Open Library actually reports one for that edition; a bare ISBN is no longer treated as proof that a cover exists. Films and TV use TMDB; the token stays only in this browser and is never included in your exported archive.

Ready. Enrichment is conservative: if a match is unclear, the work is left alone.

Catalogue access

Open Library works without a key. To also search Google Books, create a Google Books API key ↗, enable Books API in that Google Cloud project, and paste it below. Restrict the key to Books API and this site's web addresses. Standard Google API quotas apply.

The key stays in this browser, outside archive backups. Book searches send the query to Open Library and, when configured, Google Books.

TMDB

Needed for film/TV posters, directors, runtime, genres and title search. Paste a TMDB API Read Access Token here. It is stored only in your browser's local storage.

The Add experience dialog now searches your own library first. Books then search Open Library and, with a key, Google Books; films and TV search TMDB when this token is configured.

This product uses the TMDB API but is not endorsed or certified by TMDB.

Import

Letterboxd export

Choose the ZIP that Letterboxd gives you. The importer combines watched, ratings, diary, reviews and likes instead of importing them as duplicates.

StoryGraph export

Choose the StoryGraph CSV. Read, currently-reading, to-read and DNF statuses are preserved, together with dates, rating, review, format and ISBN/UID.

Generic CSV

For theatre, games or other media later. Recognised fields include Title, Type, Creator, Start Date, End Date, Rating, Review, Tags and Status.

Backups & data safety

Your archive is saved online in Supabase. Export JSON backups regularly. Restoring replaces your online archive, including publication settings.
