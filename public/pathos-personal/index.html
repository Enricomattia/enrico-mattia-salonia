Metadata & covers

Nothing here changes your ratings, reviews or dates. Enrichment only adds catalogue information. For books with a StoryGraph ISBN, v0.4 resolves the exact edition first and keeps edition metadata on the reading itself.

Enrich your existing archive

Books use Open Library and need no account. ISBN-based StoryGraph entries are treated as exact editions, not merely as works. A cover is now saved only when Open Library actually reports one for that edition; a bare ISBN is no longer treated as proof that a cover exists. Films and TV use TMDB; the token stays only in this browser and is never included in your exported archive.

Ready. Enrichment is conservative: if a match is unclear, the work is left alone.

TMDB access

Needed for film/TV posters, directors, runtime, genres and title search. Paste a TMDB API Read Access Token here. It is stored only in your browser's local storage.

The Add experience dialog now searches your own library first. Books then search Open Library automatically; films and TV search TMDB when this token is configured.

This product uses the TMDB API but is not endorsed or certified by TMDB.

Import

Letterboxd export

Choose the ZIP that Letterboxd gives you. The importer combines watched, ratings, diary, reviews and likes instead of importing them as duplicates.

StoryGraph export

Choose the StoryGraph CSV. Read, currently-reading, to-read and DNF statuses are preserved, together with dates, rating, review, format and ISBN/UID.

Generic CSV

For theatre, games or other media later. Recognised fields include Title, Type, Creator, Start Date, End Date, Rating, Review, Tags and Status.

Backups & data safety

Your archive is stored only on this device, in an IndexedDB database. No sign-in or cloud account is needed. Export JSON backups regularly, especially before deleting browser data, reinstalling your operating system or changing devices.

Reset my local archive

Permanently clear this device's Πathos Personal collection. Export a backup first.
